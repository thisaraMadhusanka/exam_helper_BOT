# Project pack notes

- The project pack contains the documentation baseline and Supabase schema, not a completed application implementation.
- Start an AI coding agent with `PROMPT.md` and instruct it to implement Phase 1 only.
- The prompt intentionally prohibits Phase 2 and Phase 3 work until the owner explicitly approves each phase.
- `frontend.env.local.example` is provided as a template; copy it to `frontend/.env.local` during local development.
- The backend `.env.example` is stored at the repository root for clarity; copy values into `backend/.env` locally.
